# 贸语通 TradeLingo

> 外贸与国际物流英语学习平台 · 单文件 Web 应用，双击即用，数据存在本机浏览器

一个面向外贸与国际物流从业者的英语学习工具。不需要安装、不需要联网注册、不依赖任何框架——下载一个 `index.html` 就能开始学。

## 功能

**单词学习**
- 列表模式：搜索、标签筛选、范围筛选（全部 / 未掌握 / 待复习 / 生词本 / 错题本 / **自定义词单**）、点击查看详解
- **词单（自定义生词本）**：在「📚 词单」里新建、重命名、删除词单；一个单词可同时属于多个词单，与「生词本」互不冲突；选中某个词单后，卡片记忆 / 连读 / 听写 / 测验都只在这个词单里取词
- **批量管理**：勾选单词（支持全选本页）后可批量加入词单、加入或移出生词本、批量删除（进回收站），词单视图下还能一键移出本词单
- 分页：每页 20 / 50 / 100 / 全部可选，上一页 / 下一页自动禁用越界按钮，翻页选项会被记住
- **连读模式**：一键把当前筛选结果（不受分页限制，比如 100 个）顺序听一遍——每个词播完自动跳下一个，可调间隔（0.6–3 秒）、每词遍数（1–3 遍）、语速，可暂停 / 继续、上一个 / 下一个、点词表任意位置跳转；整轮听完自动停下，可「再听一遍」
- 卡片记忆：点击翻面，按「认识 / 模糊 / 不认识」评分，自动优先复习薄弱词

**句子学习**
- 按业务场景分类（询盘 / 报价 / 装运 / 支付 / 索赔 / 物流跟进…）
- **搜索 + 场景筛选 + 状态筛选**（全部 / 待复习 / 未掌握 / 已收藏），句子多了也找得到
- 分页：每页 20 / 50 / 100 条可调，翻页设置会被记住
- 默认模糊隐藏译文，先自己回忆再核对；可一键「显示译文」
- **＋ 收生词**：把当前筛选句子里词库没有的词一次性收进词库（自动过滤 the/a/of 这类虚词），加入后自动联网补中文释义，也可以手动改
- 每句独立记录掌握度与复习间隔，和单词共用同一条记忆曲线
- 两种句题：**关键词填空**（挖掉业务关键词，给中文提示）、**整句听写**（听音写全句，标点与大小写不计，匹配度 ≥85% 判对）

**📊 学习统计**
- 近 5 周学习热力图：颜色深浅 = 当天练习次数，一眼看出有没有断
- 连续打卡天数 + 历史最长连续
- 掌握度分布条：未学 / 初识 / 熟悉 / 已掌握 / 熟练 / 精通各多少词
- 近 7 日练习趋势柱 + 最需要巩固的 5 个词（点击直接看详情）
- 每日目标：设置每天练多少「次」，总览顶部进度环实时显示，达标转绿

**🔊 发音朗读**
- 三种引擎：自动（在线优先、失败回退本地）/ 在线 / 本地语音合成（离线可用）
- 美音 `en-US` / 英音 `en-GB` 可切换，语速 0.6–1.3x 可调
- 发音按钮覆盖单词列表、详情弹窗、例句、卡片、句子、测验题干与答错反馈
- **四级兜底，点了就一定有声音**：有道主口音 → 有道另一口音 → 百度 TTS → 本地语音合成。有道 `dictvoice` 是词典发音，词组常缺某一口音、整句一律没有，所以后两级是必需的
- 整句朗读自动走百度 TTS（支持整句）或本地合成，不会先浪费两次注定失败的请求
- 「数据管理 → 发音自检」一键显示本地音色数量与在线音源实际状态，出问题不用猜

**🔤 悬停查词**
- 鼠标滑过句子或例句里的任意英文单词，弹出词义卡片（单词、音标、词性、释义 + 朗读）
- 三级词典兜底：**你的词库 → 内置常用词库（约 500 条，含通用高频词、外贸术语与主要港口）→ 在线词典**
- 悬停有 200ms 意图延迟：本地词库命中立刻出卡片，本地没有才联网——鼠标扫过整句不会连发几十个请求
- 词组整段识别：`Bill of Lading`、`Letter of Credit`、`L/C` 不会拆成单个词
- 词形自动还原：`cartons → carton`、`shipped → ship`、`quantities → quantity`
- 卡片上的单词可点击 → 直接打开单词详情；「＋ 加入词库」把生词一键收进词库

**🔁 间隔重复**
- 认识 → 等级 +1，按 1 / 2 / 4 / 7 / 15 / 30 天安排下次复习
- 不认识 → 等级归零、10 分钟后重来；模糊 → 12 小时后重现
- 单词与句子各自独立计算，互不影响
- 顶部与侧栏「待复习」角标，总览一键进入到期复习

**✏️ 测验中心**
- 英译中、中译英、单词拼写三种题型混合出题
- 听写模式：听发音写单词，可显示首字母提示
- 句子练习：关键词填空与整句听写混合，优先抽到期与薄弱句
- 答对提升掌握等级并延长复习间隔，答错记入错题本并缩短间隔
- 答题界面右上角可随时「退出测验」，已答过题会先确认，避免误触丢成绩

**🗂️ 数据管理**
- 导入：拖拽 / 选择文件 / 直接粘贴。自动去除 BOM 与代码块标记，字段名中英文都认（term / word / 单词，translation / 释义 / 中文），支持嵌套包装、单个对象、Excel 另存的 CSV 两列表与纯文本词表；自动去重
- 导出的备份文件可以回导，**学习进度（等级、对错、生词本、复习时间）不会丢**
- 多种导出：CSV（Excel、WPS 直接打开，带 UTF-8 BOM）、TXT 纯词表、Markdown 表格、JSON
- 导出范围可选：全部 / 待复习 / 生词本 / 错题本 / 未掌握 / 已掌握；内容可选是否带学习进度
- **回收站**：删除的单词与句子先进回收站，保留 30 天，可逐条恢复或彻底删除
- **自动快照**：导入 / 清空 / 回滚前自动存一份（最多 3 份），可一键回滚到任意一份
- 清空数据需要手动输入「清空」二字，避免误触

**其他**
- 生词本 / 错题本（答错自动进、答对自动出）
- 条目可编辑、可删除，AI 提取错了能直接改
- 今日任务卡：待复习、生词本、错题、今日练习次数，配每日目标进度环
- 键盘快捷键：卡片模式 `空格` 翻面、`1/2/3` 评分；连读模式 `空格` 暂停/继续、`←/→` 上一个/下一个、`Esc` 退出；测验 `1–4` 选答案、`Enter` 下一题、`Esc` 关弹窗
- 旧版本数据自动迁移，无需重新导入

## 快速开始

1. 下载 `index.html`，用 Chrome 或 Edge 双击打开（无需服务器）
2. 进入「数据管理」→「载入示例数据」，立即体验全部功能
3. 要导入自己的词库：把 **《AI数据制作指南.md》** 连同素材（教材截图、Word/PDF、Excel 词汇表）一起发给 AI，它会输出符合规范的 JSON；回到「数据管理」上传或粘贴即可

## 数据与隐私

- 所有数据保存在浏览器本机 `localStorage`（键 `tradelingo_v1`；在线查词缓存 `tradelingo_dict_v1`；自动快照 `tradelingo_snap_v1`）
- 不上传任何服务器、不需要注册登录
- 换浏览器或清理缓存会导致数据丢失，建议定期用「数据管理 → 导出全部数据」备份

## 技术要点

- **零依赖单文件**：原生 JavaScript + CSS，无构建步骤、无第三方库
- **词组识别**：先把命中的词组替换为占位符再逐词包标签，避免嵌套错配；正则不使用 lookbehind，兼容旧版 Safari
- **词形还原**：`s / es / ies / ing / ed / 's` + 双写辅音 + 补 `e` 多规则回退，并设最小长度阈值避免误判（如 `used` 不会被当成 `us`）
- **在线查词**：`api.dictionaryapi.dev`（音标与英文释义）+ MyMemory（中文释义），结果缓存到本机（写盘做了合并，避免每查一词就序列化整个缓存）；同一个词并发查询会合并成一次请求；机翻若原样返回英文、或结果里没有汉字，一律按「没查到中文」处理
- **失败策略**：单个词查不到不封禁在线查词；只有两个源都无响应的网络级失败连续 4 次，才暂停 30 秒。有道 `dict.youdao.com/jsonapi` 因不返回跨域许可头未采用（实测 `Access-Control-Allow-Origin` 缺失）
- **发音**：四级兜底——有道主口音 → 有道另一口音 → 百度翻译 TTS → `speechSynthesis` 本地合成。`onplaying` 触发才判定在线播放成功（`oncanplay` 仍可能被自动播放策略拦下）；连续点击产生的 `AbortError` 属正常打断，不记为失败；`NotAllowedError` 只提示补一次点击，不封禁在线音源
- **连读串播**：`speak()` 增加 `onDone(ok)` 完成回调（在线靠 `audio.onended`，本地靠 `utterance.onend`），播完再按间隔进入下一个；另设看门狗超时，避免某个音色既不触发 `onend` 也不触发 `onerror` 时整轮卡死
- **界面**：靛蓝 + 石板灰现代 SaaS 风格，响应式布局
